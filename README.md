One original funny line of wedding vows for a robot couple, entered in make.fun's "One-Line Robot Wedding Vows" bounty.

## Run it

```sh
python3 main.py
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
